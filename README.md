# UBC Hackathon 2026 — HQ

Home base for the University Blockchain Conference 2026 Hackathon.
Online Nov 13–20, finals Nov 21 at UT Austin. $22,000+ in prizes.

Start with [docs/hackathon-brief.md](docs/hackathon-brief.md).

## Layout

| Folder | What goes here |
|---|---|
| `docs/` | Rules, tracks, prizes, timeline, submission checklist |
| `ideas/` | One markdown file per idea, scored against the judging criteria |
| `research/` | Notes on sponsor tools (x402, Circle, Solana Agent Kit, Gemini PM API, QuickNode Streams, ElevenLabs, Grok Bot) |
| `demos/` | Demo scripts, video storyboard, pitch deck |
| `project/` | The actual build. **Nothing here before Nov 13 12:00 PM CST** (rule: must be built during the hackathon) |

## Key dates (CST)

- Nov 12, 6 PM: kickoff call
- Nov 13, 12 PM: hacking starts
- Nov 20, 12 PM: submit on Devpost
- Nov 21: finals in Austin (in-person required to win)
